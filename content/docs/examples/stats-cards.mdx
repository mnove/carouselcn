## Use Case

Stats and metrics carousels are ideal for:
- Dashboard KPI displays
- Analytics and performance showcases
- Business metrics on landing pages
- Progress tracking and reporting

## Features

- **4-column layout** - Compact display of multiple metrics
- **Trend indicators** - Visual up/down arrows with color coding
- **Icon integration** - Contextual icons for each metric
- **Number formatting** - Large, readable values
- **Color-coded trends** - Green for positive, red for negative changes

## Tips

- Use abbreviations (K, M, B) for large numbers to save space
- Color code trends appropriately (green = good, red = bad)
- Consider animating numbers on initial load for visual interest
- Keep metric labels short and descriptive
- Use consistent icon sizes and styles across all cards
